Specful · brand identity

A square cut once in vermilion, a wordmark cut from Lora in ink, and the tokens to carry both.

Built for a repository first. The same colour and type tokens carry a documentation site without further design work. Monochrome is part of the identity, not a degraded fallback.

The symbol

Two parts of one square, held in register.

An 18-unit square on a 32-unit grid, cut once by a step that displaces the division across a ledge set above centre. The step reads as alignment. It is not a diagram of the information model, which supports many-to-many relationships the symbol does not attempt to show.

Wordmark and lockup

Fixed outline artwork, never live text.

Cut from Lora at weight 600 and converted to outlines, so the wordmark is independent of the fonts a reader has installed. It is never re-set in a font at display time.

Why these numbers

Symbol height was tested at 1.00 through 1.36 × cap. At 1.00 the symbol reads as a bullet beside the word; by 1.36 it towers over the cap line. 1.24 is where the two read as peers.

Gap was tested at 0.30, 0.40 and 0.54 × symbol width; tracking at −12, −6 and 0. Outside those middle values the elements either crowd or disassociate.

Typography

Three faces, three jobs, one licence.

Lora is a brand face and stays scarce. Source Sans 3 carries prose, navigation, controls and routine documentation headings. JetBrains Mono carries anything a machine reads back.

Lora 600 · wordmark artwork · SIL OFL 1.1

Source Sans 3 · body, navigation, controls, documentation headings · SIL OFL 1.1

JetBrains Mono · code, commands, paths, identifiers · SIL OFL 1.1

The identity asks nothing of the CLI. Plain-text output is appropriate terminal presentation, and nothing here depends on the binary printing a mark. Whether specful ever prints one is an open product decision; if it does, suppress it when stdout is not a TTY, when --json is set, and in CI.

Colour

Vermilion is the identity. It is not the button colour.

Three layers, deliberately not the same thing. Brand values are fixed and belong to artwork. Accent is the brand colour doing interface work — links, focus, identifying details. Action is neutral, because a solid warm-red control reads as destructive whatever the token is called. The brand marks the product; it does not operate the interface.

Rules that came out of testing

Links carry the accent and an underline. Colour alone never distinguishes a link.

Code surfaces are neutral. Accent text on the accent tint measures 4.11:1, below the floor for normal text, so inline code is ink on the neutral sunken surface. --sf-accent-strong exists for cases that genuinely need accent text on a tint, and is the only value that clears it.

Status never means anything by colour alone. Pair it with a label, an icon, or both. No hue makes meaning unambiguous on its own.

Contrast record

Twenty-one text and boundary pairs computed against WCAG 2.1 minima in both themes. No pair fails. Narrowest margins: the accent as link text at 4.51:1, accent-strong on its tint at 4.52:1, and border-strong against the page at 3.09:1 light and 3.04:1 dark.

Danger sits at a deeper crimson than a conventional red. That is a design choice for legibility beside vermilion, not a threshold that had to be met — perceptual distance is a diagnostic, not a pass/fail gate.

The accent doubles as the GitHub badge fill: 4.75:1 against light and 3.98:1 against dark, so no separate badge colour is needed.

Space, corners, dividers, focus

A short vocabulary, used consistently.

Space4 px base. 4, 8, 12, 16, 24, 32, 48, 64, 96. Use scale steps, not arbitrary values.
Corners6 px inputs and small controls · 10 px buttons · 16 px cards and panels · full for pills
DividersOne pixel. Prefer a rule above a group over a box around it; four-sided borders make a document look like a brochure.
Focus2 px accent ring at 2 px offset, on every focusable element.
Measure68ch maximum for prose.

Three things this snippet gets right

alt="Specful" is the whole accessible name. The masthead shows the word, so the alt text is the word: not "Specful logo", which reads "logo" aloud to no purpose.

The light file is the <img> fallback, so anything that ignores <picture> still gets readable artwork.

No release number in the artwork. Version information belongs in a badge or in prose, where it can change without re-cutting a file.
